# Getting help

| I want to… | Go to |
|---|---|
| Understand how a bounty works | [README](README.md) and [CONTRIBUTING.md](CONTRIBUTING.md) |
| Find an Intent or mission | `./tb map`, `./tb search <term>`, or [docs/INTENTS.md](docs/INTENTS.md) |
| Report a missing capability or gap | [Open an Issue](../../issues/new/choose) using a form |
| Ask whether a reward exists | Read the Issue's `## Reward` section. If it is absent, no reward is committed |
| Report a vulnerability or sensitive finding | **Do not use a public Issue.** Follow [SECURITY.md](SECURITY.md) |
| Ask about Telegraph itself | [Telegraph docs](https://docs.telegraphprotocol.com/) |

Maintainers triage public Issues on a best-effort basis. Posting a gap does not create a bounty, a reward or a commitment to build anything.
